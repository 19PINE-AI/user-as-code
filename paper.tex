\begin{abstract}
Current personalization in AI agents primarily relies on Retrieval-Augmented Generation (RAG) over unstructured text, structured knowledge graphs, or flat fact stores. While effective for basic recall, these ``Bag of Facts'' approaches struggle with the specific challenges of user memory: resolving conflicting information, managing temporal dependencies, and enforcing logical constraints. This paper introduces \textbf{User as Code}, a paradigm where an agent's understanding of a user is maintained as a \textbf{modular, version-controlled software project}. Our core observation is that \textbf{code is the only representation format that unifies readability and verifiability in a single medium}: the same Python that stores a user's passport expiry date can also express---and execute---the assertion that the expiry is too close to a booked flight. We propose a two-phase architecture: (1)~append-only fact extraction that never loses information, and (2)~periodic structuring into typed Python dataclasses. This enables a \textbf{generate-verify-review loop} where the coding agent generates Python constraints, the interpreter verifies computation deterministically, and pre-computed alerts are surfaced in a compact manifest. We evaluate on LOCOMO, LongMemEval, and a novel Active Service benchmark against Mem0, A-MEM, and full-context baselines. User as Code achieves 81.7\% on LOCOMO (94\% of full-context), ties full-context on LongMemEval at 79.2\%, and achieves 100\% proactive alert detection on Active Service---a capability where existing memory systems have no equivalent mechanism.
\end{abstract}
