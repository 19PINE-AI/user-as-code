\begin{abstract}
Current personalization in AI agents relies on retrieval over unstructured text, knowledge graphs, or flat fact stores. These ``bag-of-facts'' representations recall well but struggle to resolve conflicting reports, track temporal dependencies, and enforce logical constraints. We introduce \textbf{User as Code}, a paradigm in which an agent's understanding of a user is maintained as a modular, version-controlled software project of typed Python dataclasses and executable constraints. The contribution is a \emph{two-phase pipeline} that converts unstructured conversation into this representation---append-only fact extraction followed by periodic LLM-driven structuring into typed code---so an interpreter can run constraints deterministically and surface pre-computed alerts. (We borrow the append-log / periodic-checkpoint shape from database systems; the novelty is in applying it to LLM memory and using typed code as the checkpoint medium.)

Evaluated symmetrically against five external memory systems on the same Gemini~3 Flash backbone, UaC reaches \textbf{78.8\%} on the full 10-conversation LOCOMO benchmark (600 QAs; within 1.0pp of the 79.8\% full-context upper bound, McNemar $p{=}0.65$---statistical tie) and \textbf{83.0\%} on the full 500-question LongMemEval benchmark, statistically tying MemMachine ($84.8\%$, $p{=}0.33$) and significantly ahead of EverMemOS, Hindsight, A-MEM, and Mem0 ($p<0.005$). A new 100-case analytical-inference benchmark separates representations by class: retrieval-only memory collapses on aggregation (Mem0 6\%, MemMachine 43\%) while code-executable representations stay near 100\% (UaC~v5 99\%, Full Context + REPL 100\%). Instrumented Gemini calls show UaC's one-time structuring pays back after $\sim$3 repeated queries against the same user state and costs $\sim$15$\times$ less than reloading raw records every query when amortized over 100 queries. Replacing Gemini~3 Flash with GPT-5.4 across extraction, structuring, and answer generation recovers \textbf{80.8\%} on a 2-conversation LOCOMO subset (120 QAs)---statistically tied with the Gemini run on the same subset (82.5\%, McNemar $p{=}0.82$). On a 60-scenario Active Service benchmark, UaC's constraint pipeline reaches 100\% alert detection on standard scenarios and 85\% on hard multi-step-arithmetic scenarios; we are not aware of an analogous pre-computation mechanism in published memory systems, though some (EverMemOS Foresight, Hindsight Opinion) include partial pre-computation. The SOTA comparisons use minimal-faithful reimplementations on the same backbone; we document fidelity in Appendix~\ref{app:reimpl} and treat the original published numbers as ceilings for those architectures rather than direct competitors.
\end{abstract}
